# Skyscrapers

- Provides a first occupation reward,
- Provides passive financial strength
- Provides a unique UR girl.
- There are two levels of Skyscrapers: Zone 1 and Zone 2.
  - Only one Skyscraper per zone can be held.
    - Meaning the maximum number of UR girls that can obtain from Skyscrapers is two.
- Prioritise securing these strategic landmarks to maximise their rewards and benefits.
