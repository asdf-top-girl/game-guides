# Landmarks

- Holding landmarks provides passive financial strength, with eight levels of landmarks available for possession.
  - Each landmark owned increases financial strength passively.
- Holding multiple landmarks of the same level, such as two level-1 landmarks, does not provide additional financial strength.
  - For the benefit of the server, it is better to share such landmarks.
- It is recommended to first secure the first occupation reward before releasing the landmark to other groups later.
  - This ensures both group progress and server cooperation.
