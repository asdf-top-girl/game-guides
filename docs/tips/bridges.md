# Bridges

- The map is divided into zones separated by rivers, which can only be crossed if your group owns a bridge.
- Controlling multiple bridges is crucial for two reasons.
  - First: conquering bridges provides first occupation rewards.
  - Second: owning bridges gives strategic control over which groups can access different zones.
- As you move closer to the Burj Khalifa, resource levels, such as Garden Hotels and Stadiums, become higher, making it essential to secure bridges to access these valuable zones and maintain an advantage.
