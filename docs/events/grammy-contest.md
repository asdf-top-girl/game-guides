# Grammy Contest

## Tips

1. Build the right lineup
- Match the genre: EDM, Hip-Hop, Pop, R&B or Rock.
2. Equip accessories
- Jewelry, Cars, Houses.
3. Run multiple times
- Critical Hits are random events that influence performance.
- Running multiple times swing the chances in your favour.
4. Collections and Artifacts
- Artifacts from the Collection functionality gives massive boost
